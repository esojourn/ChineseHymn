# 双语逐句阅读预览

`tools/paired-reading-sync.py` 用于英文演唱、中文译文分段列出的歌曲。目前配置为 06-004《我要跟从你》。原 `.txt` 和音频不变；同步文件的 `textLayout.lineOrder` 只改变播放页和编辑器的显示顺序。校验器要求它是全部原文行号的完整排列，标题、空行和正文都不能删除或重复。

每个阅读区域包含一行英文及对应中文。第一段末两句中文按语义分别对应英文第八、七句，显示时配对，源文件保持原样。原文共有 40 组句子，实际演唱顺序为第一段、副歌、第二段、重复副歌、第三段、结尾副歌，共 48 个阅读位置。

出版方的原始练习旋律用于确定完整顺序和声学取样窗口。整曲 STFT 检查保留原有成本、调性区分和跨度要求；未通过的 CQT、和声诊断不作为已通过路径，也不声称原谱音符经过独立光学识别。最终位置是阅读预览，不是精确起唱时间。

两组固定上下文窗口提供普通阅读位置。四处首词截短或时长过短的位置必须在配置中明确列出：两组窗口整体检查通过、首词末端相差不超过 0.5 秒、与原谱窗口估计相差不超过 1.5 秒，并且后续至少四个上下文词的正时长边界分别在 0.5 秒内一致。此时用一致词尾提前一秒预览，不把上下文强制对齐误称为逐词自由识别。原始概率、短词和未核实文字全部保留于证据。

副歌回跳和长间奏后的非相邻跳转另须由两个独立、无提示、完整音频转写唯一确认原文开头，两者首词起止边界均须在 0.5 秒内一致；跳转不能隐藏尚未结束的前句。初始区域从零秒显示，间奏期间保持上一阅读位置。

重建命令：

```sh
.venv/bin/python tools/paired-reading-sync.py \
    --cache sync-drafts/bulk/experiments/paired-reading-warm --songs 06-004
```

缓存需放入配置指定的出版方原始练习 JSON；程序验证其 SHA-256。默认从已归档、绑定歌词及录音哈希的 96 组原始声学窗口重建，重新计算旋律路径、文本排列和时间轴；这不代表重新运行语音模型。加 `--measure` 可使用配置固定的本地 medium 模型、tokenizer 和库版本重新测量全部上下文窗口，断点按完整输入指纹保存。两个完整自由转写作为独立输入，也须通过配置中的原始文件哈希验证。

发布前必须比较独立缓存重建结果，并在五种屏幕尺寸下检查全部阅读区域、全部实际音频跳转，以及相邻移动前后两组中英文均保持可见。此显示模式只影响明确携带该配置的同步数据。
