## 制作依据

以仓库原始歌词及领唱为依据，使用本地 faster-whisper medium/int8 对已知歌词做强制对齐，再用重叠音频片段核对换段。普通歌声转写出现明显误识别，未直接采用其转写结果。图片区域按原谱面检查，保留三段交错排版。

两版音频通过 0.1 秒步长的色度特征和动态时间规整（DTW）匹配。以下映射残差只反映两条音乐时间轴的一致性，不是歌词边界的实测误差。模型首词容易吸收前奏或静音，因此两首首句起点仍是估计值；拖腔结束点也是试听重点。

## 预览与验收

1. 启动 PHP 本地服务，打开 `tools/sync-editor.html`。
2. 选择该曲原始 TXT/JPG 和两份 MP3，再导入 `data/sync/` 中对应 JSON。
3. 选择音轨并勾选预览。分别完整播放领唱和伴奏，重点核对表中边界、首句、回滚区间及最后一屏；在手机横竖屏检查阅读区域。
4. 如需修正，修改时间或区域后点击“导出并启用”替换 JSON，无需逐音轨勾选审核。运行 `npm run sync:validate`。
