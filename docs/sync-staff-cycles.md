# 完整五线谱诗节循环

`tools/staff-cycle-sync.py` 处理原词由完整短诗节组成、每节使用同一完整曲调的歌曲。目前配置为 01-270《佳美脚踪》，原文及两版 MP3 均不改动。

[《生命圣诗》270 条目](https://hymnary.org/hymn/HOLC1986/270) 将本曲中文首句对应到 Ralph Harrison 的 Cambridge 曲调。[CCEH 原始档案](https://ccel.org/cceh/0007/x000790.htm) 提供相互配套的原始 MIDI 和矢量 PDF。先前同名歌词的 St. Michael、St. Thomas、Venice 候选不能代替这份原歌本的曲调。

程序绑定原文、全部录音、原始 MIDI、PDF 及解析器版本。逐个读取两行高声部音头，同列取高音；第二行开头的低声部 D4 与高声部 E4 因二度而横向错位，只有已明确复核、确实紧邻高音且低一个线间的音头可以排除。合计 30 个原谱旋律音与未修改的 MIDI 全局符号匹配必须零编辑、唯一调性对应。四分、八分及三处附点二分节奏按原始谱面人工复核。

两条录音分别重建，不作音轨间比例换算。每条录音用 STFT、CQT 两种音频特征，分别匹配 MIDI 及原谱节奏，整曲和逐节共八条起点路径全部须在 0.5 秒内一致；继续使用原有成本、调性区分、跨度、首尾完整性及独立重复相位检查。未通过的和声编配诊断单独完整保存，不称为已通过的验证路径，也不放宽其阈值。

初始诗节从播放零秒显示，随后每节提前 1.5 秒预览。原文五节完整保留，浏览器还须检查当前区域、下一行预读和两条录音的全部实际跳转。此结果不声称自由转写识别到了歌词，不据此判断录音是器乐、哼唱还是人声；阅读位置来自已核对的完整曲调循环，不是精确起唱时间。

重建命令：

```sh
.venv/bin/python tools/staff-cycle-sync.py \
    --cache sync-drafts/bulk/experiments/staff-cycle-warm --songs 01-270 --prepare
```

`--prepare` 下载配置固定哈希的原始 PDF 和 MIDI；也可预先复制这两个原始文件到配置指定的缓存路径，然后去掉此参数。独立缓存应重做音符提取、音频特征、完整路径及全部时间轴，并与已核对结果比较。
