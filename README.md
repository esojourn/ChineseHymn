# Chinese Hymn / 中文赞美诗

为教会网络敬拜、个人灵修唱诗提供中文赞美诗歌词、曲谱和伴奏，支持手机与电脑浏览。

网站使用 PHP 动态生成目录和播放页，直接读取 `data/` 中的歌曲素材，无需数据库或构建步骤。

演示地址：[敬拜赞美](https://dingxuan.info/hymn/)

## 主要功能

- 歌曲目录搜索、分类筛选，以及显示或隐藏无伴奏歌曲。
- 显示文字歌词或原始曲谱图片，播放配套音频。
- 部分歌曲提供伴奏与领唱版本，可设置优先使用领唱。
- 自动播放、单曲循环与 Cookie 设置保存。
- 按音频时间轴自动滚动歌词或曲谱，支持手动接管和恢复跟随。
- 使用 `Ctrl + ←`、`Ctrl + →` 后退或前进 10 秒。

## 本地运行

安装 PHP 并启用 `mbstring` 扩展，在项目根目录执行：

```sh
php -S localhost:8080
```

访问 [本地目录页](http://localhost:8080/index.php)。`index.html` 会自动跳转到 `index.php`。

## 部署与更新

部署到支持 PHP 的 Web 服务器，并启用 `mbstring`。项目可放在站点根目录或 `/hymn/` 等子目录，资源路径会根据入口地址自动计算。

音频通过 `audio.php` 提供，支持分段读取，供播放器拖动进度及快捷键定位。部署时需包含 `index.php`、`lib.php`、`audio.php`、`data/`、`css/` 及配套的 `jQuery-3.3.1/`、`DataTables-1.10.20/` 目录。

页面使用 `Cache-Control: no-cache`，每次访问会向服务器检查更新；本地样式和脚本地址自动附带文件内容哈希，文件变更后浏览器会下载新版，无需手工修改版本号。更新时应同步发布 PHP 文件及对应资源。

如使用 CDN，应保留查询参数参与缓存键，并遵循页面的缓存响应头。已经缓存且尚未向服务器检查更新的旧页面，需要等缓存过期或刷新后才能获得新策略。

## 添加或修改歌曲

将歌词、曲谱和音频放入 `data/`，文件名由两位分类编号、连字符、歌曲编号和歌名组成，例如：

```text
01-040父啊儿女称颂你名.txt
01-040父啊儿女称颂你名.mp3
01-040父啊儿女称颂你名-领唱.mp3
```

文字歌词使用 UTF-8 编码的 `.txt` 文件，图片曲谱使用 `.jpg` 文件。配套音频使用相同文件名主体，领唱录音在扩展名前追加 `-领唱`。PHP 会在访问时扫描目录，新增、删除或重命名素材后无需生成目录文件。

修改已有同步数据的歌词、曲谱或音频后，需要重新校准；素材校验不通过时，播放器会停用该曲的自动滚动，仍可正常播放和手动阅读。

## 歌词自动滚动

菜单中的“自动滚动”默认开启，并保存用户选择。同步数据已启用且素材校验通过的歌曲可按播放进度跟随，前奏和间奏可平滑移动到下一阅读区域；暂无同步数据的歌曲仍可正常播放、手动阅读。

文字歌词按阅读区域居中，图片保持原始曲谱并尽量露出下一句。手动滚动会暂停本次跟随，点击右下角按钮可恢复。

本地启动后，访问 [同步校准工具](http://localhost:8080/tools/sync-editor.html) 制作和试听时间轴。导出的同步文件放入 `data/sync/`，文件名为原歌词文件名加 `.json`。完整操作、素材校验、可选 OCR/音频对齐及测试方法见 [自动滚动指南](docs/lyric-sync.md)，批量处理进度见 [全库滚动数据记录](docs/sync-bulk.md)。

## 项目结构

- `index.php`、`lib.php`：歌曲目录、歌词显示与播放器。
- `audio.php`：音频分段读取接口。
- `data/`：歌词、音频、曲谱及 `sync/` 下的同步数据。
- `css/`：页面样式、菜单设置及自动滚动逻辑。
- `tools/`：同步校准工具及离线辅助制作工具。
- `tests/`、`docs/`：验证脚本、使用指南和同步制作记录。
